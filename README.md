📊 Executive Sales Performance Dashboard | Power BI

 📌 Project Overview

The Executive Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI and Excel.

The objective of this project is to analyze sales performance, monitor key business metrics, and transform raw sales data into meaningful business insights.

The dashboard provides insights into revenue, orders, gross profit, gross margin, and quantity sold through interactive visualizations.

 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor revenue and profitability.
- Identify top-performing countries.
- Analyze product category performance.
- Evaluate sales channel performance.
- Track monthly and quarterly sales trends.
- Support data-driven business decisions.

🛠️ Tools & Technologies

- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

 📈 Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Total Gross Profit
- Gross Margin
- Total Quantity

📊 Dashboard Features

1. **Sales Performance Analysis:** Analyze revenue and gross profit.
2. **Country-wise Sales Analysis:** Compare sales across different countries.
3. **Product Category Analysis:** Understand product category performance.
4. **Sales Channel Analysis:** Compare revenue across sales channels.
5. **Time-based Analysis:** Explore monthly and quarterly sales trends.
6. **Interactive Filters:** Analyze data using country, month, quarter, and product category filters.

 📂 Dataset

The project uses an Excel dataset as its primary data source.

**Dataset File:** Sales_Data.xlsx

The dataset is used to analyze sales revenue, orders, gross profit, product categories, countries, and sales channels.

 💡 Business Value

This dashboard helps business stakeholders:

- Monitor important sales KPIs.
- Understand revenue distribution.
- Compare country-wise sales performance.
- Evaluate product profitability.
- Identify sales trends.
- Make informed business decisions.

 🚀 How to Run This Project

1. Download or clone this repository.
2. Download the Excel dataset from the Dataset folder.
3. Open the PBIX file using Microsoft Power BI Desktop.
4. If prompted, update the Excel data source path.
5. Refresh the dataset.
6. Explore the interactive dashboard.
